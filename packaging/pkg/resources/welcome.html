ZTab

A Windows-style window switcher: hold ⌥ and press Tab to see every window, grouped by app; ⌥` switches between the windows of the current app.

Choose where to install it on the Installation Type step (Change Install Location…):

  • Install for all users of this computer: the Applications folder; asks for an administrator's password. Other users turn on start at login in their own ZTab Settings.
  • Install for me only: Applications in your home folder; no password needed.

Either way ZTab starts at login for you, unless you had turned that off in an earlier install (change it any time in ZTab's Settings). Installing for all users replaces your own “me only” copy.
